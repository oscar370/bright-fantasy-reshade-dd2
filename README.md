# Bright Fantasy Reshade (DD2)

Preset created by [kakasi104](https://www.nexusmods.com/profile/kakasi104). [Original preset](https://www.nexusmods.com/dragonsdogma2/mods/609).

Because the original preset has not been updated on Nexus, it may not work properly with newer versions of Reshade.

The preset in this repository is created using a GitHub workflow. The effects used by the preset are not stored here; they are cloned during the build process. **This ensures that you receive the most up-to-date effects**.

## Install

- Install Reshade; install only the standard effects.
- Download the `.zip` file from the releases section.
- Extract the zip into the game folder.
- Open the game and select the preset from the Reshade menu.

> Linux/Proton: install `d3dcompiler_47` in the prefix.
